redis五种基础数据类型
    1.String字符串
    2.Hash哈希(类似与map,字典)
    3.List列表(双向列表，有序可重复)
    4.Set合集(无序,元素不可重复)
    5.ZSet有序合集(每个元素都带一个分数，自动排序，元素不重复)

redis安装完，默认有16个数据库，默认为0号库 0~15

redis链接池
    1.事先初始化一定数量的链接，放到链接池中
    2.当go需要操作redis时，直接从redis链接池取出链接即可
    3.这样可以节省临时获取redis链接的时间，提高效率

基本操作CRUD
    1.添加一个key-value (set key value)
        set指令，存在则修改，不存在则添加
    2.读取key对应的数据(get key)
    3.切换数据库(select 1)
    4.查看当前数据库的key-value数量(dbsize)
    5.清空当前数据库(flushdb)
    6.清空所有数据库(flushall)
    7.删除单个数据(del key)
    8.有时间限制的setex(key seconds value)
        超时自动删除数据
    9.同时设置一个或多个key-value(mset)(mget)

具体操作
    String类型
        一个key对应一个value
        除了字符串外，也可以存放图片等二进制数据
        redis内value一个最大为512M

    Hash哈希  一个键值对集合
        hset hmset
        hget hgetall hmget
        hdel
        hlen    统计有多少元素
        hexists 判断key中有无name字段

    List列表  双向链表，元素有序，可重复
        lpush   头插法，从左边写入数据
        rpush   尾插法，从右边写入数据
        lrange key 0 -1 遍历链表
        del  
        lpop key 从左边取出数据并删除
        rpop key 从右边取出数据并删除
            pop完了，key会自动清除
        llen 返回链表长度,空为0

    Set合集 无序，不重复
        sadd key member... 
        smember key  查看所有值
        srem key member 删除指定值
        sismember key member 看key中是否有该member值
